Wellsound24 Website + Full Editable Dashboard

ไฟล์หลัก
- index.html        หน้าเว็บไซต์
- admin.html        แดชบอร์ดแก้ไขทุกส่วน
- site-content.js   ข้อมูลเว็บไซต์ที่เผยแพร่
- script.js         ระบบหน้าเว็บไซต์
- admin.js          ระบบแดชบอร์ด
- styles.css        รูปแบบหน้าเว็บไซต์
- admin.css         รูปแบบแดชบอร์ด
- assets/           โลโก้และไอคอน

เข้าแดชบอร์ด: /admin.html
รหัสเริ่มต้น: 2468

อ่านวิธีใช้งานฉบับเต็มใน README_DASHBOARD_TH.txt

อัปเดต: นำโลโก้ Wellsound24 เดิมออกแล้ว และเปลี่ยนเป็นช่องใส่โลโก้ขนาดเดิม สามารถอัปโหลดโลโก้ใหม่ได้จากแดชบอร์ด > หัวเว็บไซต์และเมนู

อัปเดตปุ่ม Facebook
- เพิ่มปุ่ม “ติดต่อทาง Facebook” ในส่วนติดต่อ
- เข้า admin.html > ติดต่อและฟอร์ม เพื่อแก้ข้อความปุ่มและลิงก์เพจ Facebook
- สามารถเปิด/ปิดปุ่ม และกดทดสอบลิงก์ได้จากแดชบอร์ด
