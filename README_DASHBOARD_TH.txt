WELLSOUND24 – FULL WEBSITE EDITOR
================================

แดชบอร์ดเวอร์ชันนี้ออกแบบให้แก้เว็บไซต์ได้เกือบทุกจุด โดยไม่ต้องเปิดโค้ด

เข้าใช้งาน
-----------
1. เปิดเว็บไซต์ตามปกติ
2. เติม /admin.html ต่อท้ายโดเมน
   ตัวอย่าง: https://ชื่อเว็บของคุณ.vercel.app/admin.html
3. รหัสเริ่มต้น: 2468
4. เปลี่ยนรหัสได้ในเมนู “บันทึกและสำรอง”

วิธีแก้แบบง่ายที่สุด
--------------------
1. เปิดเมนู “แก้จากตัวอย่าง”
2. คลิกข้อความ รูปภาพ ปุ่ม หรือเมนูในตัวอย่างด้านขวา
3. ระบบจะพาไปยังช่องแก้ไขตรงจุดนั้น
4. แก้ไขและดูผลแบบสด
5. กด “บันทึกการแก้ไข”

สิ่งที่แก้ไขได้
---------------
- ชื่อเว็บ คำอธิบาย SEO เบอร์โทร อีเมล LINE Facebook และที่อยู่
- โลโก้และไอคอนบนแท็บเว็บไซต์
- แถบเมนู: เพิ่ม ลบ เรียงลำดับ เปลี่ยนชื่อและลิงก์
- หน้าแรก: ข้อความ ปุ่ม รูปปก ตำแหน่งรูป ความมืด ความสูง และขนาดหัวข้อ
- จุดเด่นใต้หน้าแรก: เพิ่ม ลบ และเรียงลำดับ
- บริการ: เพิ่ม ลบ เรียงลำดับ แก้ไอคอน หัวข้อ และคำอธิบาย
- ส่วนจุดเด่นบริษัท: ข้อความ รายการ รูปภาพ หรือภาพเวทีจำลอง
- ผลงาน: เพิ่มรูปได้หลายรายการ พร้อมชื่อ คำอธิบาย ตำแหน่งรูป และลิงก์
- ติดต่อ: ข้อความ ปุ่ม และแบบฟอร์มทั้งหมด
- ประเภทงานในแบบฟอร์ม: เพิ่ม ลบ และเรียงลำดับ
- ท้ายเว็บไซต์และปุ่ม LINE ลอย
- สี ฟอนต์ ความกว้าง ความมน ระยะห่าง และเงาการ์ด
- เปิด/ปิดส่วนต่าง ๆ และเรียงลำดับส่วนบนหน้าเว็บ
- ดูตัวอย่างคอมพิวเตอร์ แท็บเล็ต และมือถือ
- ย้อนกลับ/ทำซ้ำด้วยปุ่ม หรือ Ctrl+Z / Ctrl+Y

การบันทึกมี 2 แบบ
------------------
1. “บันทึกการแก้ไข”
   เก็บข้อมูลในเบราว์เซอร์และอุปกรณ์ที่กำลังใช้งาน

2. “ดาวน์โหลด site-content.js”
   ใช้สำหรับเผยแพร่การแก้ไขให้ทุกคนเห็นบนเว็บไซต์จริง
   - เข้าเมนู “บันทึกและสำรอง”
   - กด “ดาวน์โหลด site-content.js”
   - นำไฟล์ไปแทน site-content.js เดิม
   - อัปโหลดโฟลเดอร์เว็บไซต์ขึ้น Vercel ใหม่

หมายเหตุสำคัญ
-------------
เว็บไซต์ชุดนี้เป็น Static Website จึงไม่สามารถเขียนไฟล์บน Vercel โดยตรงจากหน้าเว็บได้
การบันทึกในแดชบอร์ดจะติดอยู่กับเบราว์เซอร์นั้น จนกว่าจะดาวน์โหลด site-content.js
และนำไปเผยแพร่ขึ้น Vercel ใหม่

ไฟล์สำรอง
---------
- ดาวน์โหลด JSON เพื่อเก็บข้อมูลทั้งหมด
- นำเข้า JSON เพื่อกู้คืนข้อมูล
- รูปที่อัปโหลดจะอยู่ในไฟล์สำรองด้วย

ความปลอดภัย
-----------
รหัส PIN ในเวอร์ชัน Static เป็นการป้องกันระดับเบื้องต้นบนเบราว์เซอร์
หากต้องการระบบหลังบ้านออนไลน์ที่บันทึกข้ามอุปกรณ์และมีบัญชีผู้ใช้จริง
จำเป็นต้องเชื่อมฐานข้อมูลและระบบล็อกอิน เช่น Supabase หรือ Firebase


ฟังก์ชันใหม่: ปรับขนาดและลากย้ายข้อความ
- เข้า admin.html แล้วคลิกข้อความใด ๆ ในตัวอย่าง
- ปรับขนาด ตำแหน่ง X/Y ความกว้าง สี น้ำหนัก และระยะบรรทัดได้
- ลากข้อความในตัวอย่างเพื่อย้ายตำแหน่งได้โดยตรง
- ตั้งค่าแยกสำหรับคอมพิวเตอร์ แท็บเล็ต และมือถือได้
- กด “บันทึกการแก้ไข” และดาวน์โหลด site-content.js เพื่อเผยแพร่ขึ้น Vercel

อัปเดต: นำโลโก้ Wellsound24 เดิมออกแล้ว และเปลี่ยนเป็นช่องใส่โลโก้ขนาดเดิม สามารถอัปโหลดโลโก้ใหม่ได้จากแดชบอร์ด > หัวเว็บไซต์และเมนู

อัปเดต: การแก้เบอร์โทรปุ่ม “โทรสอบถาม”
- เข้าแดชบอร์ด แล้วเลือกเมนู “ติดต่อและแบบฟอร์ม”
- กรอกเบอร์ใหม่ในช่อง “เบอร์โทรสำหรับปุ่ม โทรสอบถาม”
- กด “บันทึก” เพื่อทดสอบบนเบราว์เซอร์
- เมื่อต้องการเผยแพร่ขึ้น Vercel ให้กด “สร้างไฟล์เผยแพร่” แล้วนำ site-content.js ไปแทนไฟล์เดิม

การตั้งค่าปุ่ม “คุยผ่าน LINE”
- เปิด admin.html แล้วเข้าเมนู “ติดต่อและฟอร์ม”
- แก้ LINE ID หรือเบอร์โทรที่ผูกกับ LINE ได้
- หากมีลิงก์ LINE/lin.ee โดยตรง ให้ใส่ในช่องลิงก์ ระบบจะใช้ช่องนี้ก่อน
- ปุ่ม LINE ทั้งในส่วนติดต่อและปุ่มลอยจะอัปเดตพร้อมกัน


อัปเดตปุ่ม LINE
- แก้ลิงก์ LINE ID ให้เปิดหน้าสำหรับเพิ่มเพื่อนโดยตรง
- รองรับ LINE ID แบบมีหรือไม่มี @
- รองรับลิงก์ https://lin.ee/... และ https://line.me/...
- มีปุ่ม “ทดสอบลิงก์ LINE” ในเมนู ติดต่อและฟอร์ม

อัปเดตปุ่ม Facebook
- เพิ่มปุ่ม “ติดต่อทาง Facebook” ในส่วนติดต่อ
- เข้า admin.html > ติดต่อและฟอร์ม เพื่อแก้ข้อความปุ่มและลิงก์เพจ Facebook
- สามารถเปิด/ปิดปุ่ม และกดทดสอบลิงก์ได้จากแดชบอร์ด
