WELLSOUND24 — วิธีปรับขนาดและลากย้ายข้อความ
================================================

1. เปิด admin.html และใส่รหัสเริ่มต้น 2468
2. ในตัวอย่างด้านขวา คลิกข้อความที่ต้องการแก้ไข
3. ลากข้อความในตัวอย่างเพื่อย้ายตำแหน่งได้ทันที
4. ใช้ช่อง “ขนาดข้อความ” เพื่อกำหนดขนาดเป็นพิกเซล
5. ปรับตำแหน่งละเอียดด้วยค่า X และ Y
   - X ค่าบวก = ไปทางขวา / ค่าลบ = ไปทางซ้าย
   - Y ค่าบวก = ลงล่าง / ค่าลบ = ขึ้นบน
6. สามารถปรับความกว้าง การจัดแนว ความหนา สี ระยะบรรทัด
   ระยะห่างตัวอักษร และการหมุนข้อความได้
7. เลือกแท็บ คอม / แท็บเล็ต / มือถือ เพื่อจัดตำแหน่งแยกแต่ละหน้าจอ
8. กด “คืนตำแหน่ง” เพื่อคืนเฉพาะ X/Y/การหมุน
9. กด “คืนรูปแบบทั้งหมดของจุดนี้” เพื่อคืนค่าข้อความจุดนั้น
10. กด “บันทึกการแก้ไข” เมื่อทำเสร็จ

การเผยแพร่ขึ้น Vercel
----------------------
เข้าเมนู “บันทึกและสำรอง” แล้วดาวน์โหลดไฟล์ site-content.js
นำไฟล์ไปแทน site-content.js เดิมในโปรเจกต์ และ Deploy ขึ้น Vercel อีกครั้ง
